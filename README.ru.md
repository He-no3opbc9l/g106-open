# G106 open firmware

[![Build firmware](https://github.com/He-no3opbc9l/g106-open/actions/workflows/build.yml/badge.svg)](https://github.com/He-no3opbc9l/g106-open/actions/workflows/build.yml)

[English](README.md) | **Русский**

Открытая прошивка для КВ QRP-трансивера **G106**, написанная с нуля на голом C (без HAL и
RTOS). Она заменяет стоковое приложение (V1.4b01) и работает за **нетронутым стоковым загрузчиком
XG**: шьётся так же, как официальное обновление, и стоковую прошивку можно вернуть в любой момент.

Первая цель — точное повторение стокового поведения: тот же экран, кнопки, страницы софт-кнопок,
редактор настроек, память каналов и формат EEPROM (байт в байт со стоком, включая CRC, поэтому
настройки сохраняются при переключении между стоком и этой прошивкой). Поверх этого — улучшения DSP
и интерфейса.

> **Внимание.** Это экспериментальная прошивка для передатчика. Тесты передачи — только на
> эквивалент нагрузки. **Ограничений передачи по диапазонам нет**: вы сами отвечаете за то, чтобы
> выходить в эфир только там, где разрешает ваша лицензия. Перед прошивкой сделайте резервную копию
> (калибровка в EEPROM, в идеале — весь flash). Никаких гарантий. Проект не связан с
> производителем трансивера и не одобрен им.

## Возможности

Работает на реальном трансивере:

- Главный экран со стоковым интерфейсом (оригинальные шрифты и иконки берутся из официальной
  прошивки при сборке, см. ниже; экран загрузки и экран выключения — собственные), настройка частоты, диапазоны, V/M, A/B, память (MW / MC), VER,
  окна сообщений.
- Кнопка питания как в стоке (короткое нажатие — подсветка, удержание 2 с — экран выключения и
  сохранение).
- Редактор настроек: CWF CWT CWR QSK KS KM IMB DIS MG TXP; редактор позывного (CSN) как в стоке,
  позывной показывается на экране загрузки (по умолчанию «G106 OPEN»).
- Приём: SSB, CW, AM, NFM. I/Q 48 кГц → подавление DC → адаптивная балансировка I/Q → фазовый
  SSB-демодулятор на 16 кГц (Гильберт 191 отвод), биквадные CW-фильтры, AM-детектор огибающей,
  частотный детектор NFM с деэмфазисом и шумоподавителем, полосовой фильтр, АРУ в дБ
  с упреждением.
- Панорама (БПФ 1024 точки) с зумом и S-метр на основе БПФ.
- Передача: SSB, AM и NFM с микрофона по PTT, вход данных для L-D / U-D (цифровые виды связи).
- CW-передача как в стоке: ямбический / прямой манипулятор на гнезде ключа (PA6 точка, PA7 тире;
  KS скорость, KM MAN / AUTO-L / AUTO-R, IMB режим A / B, CWR отношение тире), самоконтроль тоном
  CWT, нарастание огибающей 10 мс, время удержания QSK (короткое нажатие кнопки QSK включает/выключает передачу по ключу, как в стоке:
  при выключенном QSK ключ работает только при зажатой PTT). С настоящим ключом пока не проверено.
- Разнос (SPL, страница 4): приём на текущем VFO, передача на другом (только частота), иконка SPL,
  при передаче основная строка показывает VFO передачи; CAT 0F. В режиме памяти с разносом передачи
  нет, как в стоке.
- Приёмник WFM (встроенная FM-микросхема): поиск и каналы.
- CAT: протокол Icom CI-V на USART1, как в стоке (19200 8N1), см. [CAT](#cat).

Сознательные отличия от стока:

| | |
|---|---|
| FILT | фильтр звука RX/TX, своя ширина для каждой группы режимов: SSB, DATA (L-D/U-D), AM 2,0–6,0 кГц, NFM 2,0–3,0 кГц; срез снизу 20 Гц (NFM 300 Гц); в CW открывает CWF (страница софт-кнопок 6) |
| ZOOM | зум панорамы 1,0–3,0× (страница 6) |
| AGC | OFF / SOFT / MED / HARD (HARD = сток, OFF = фиксированное усиление) (страница 6) |
| MIC GAIN | 0..60 = 0..+30 дБ шагом 0,5 дБ (в стоке 0..30) |
| Эквалайзер, COMP | 3-полосный эквалайзер микрофона и компрессор (страница 7); в режимах данных отключены |
| Предусилитель | общий, а не на каждый VFO/диапазон |
| Переключение RX/TX | задержка реле 10 мс + плавные фронты 10 мс, без ограничений по диапазонам |
| AM TX | микрофон +12 дБ перед лимитером (модуляция ≤ 90 %) |
| NFM | включён в цикл кнопки MODE (в стоке есть в списке, но отключён): девиация ±2,5 кГц, пред-/деэмфазис 6 дБ/окт; SQL = шумоподавитель OFF / 1..30 по уровню S-метра (2 дБ на шаг), порог показан стрелкой над S-метром (страница 6) |

Пока не сделано (до паритета со стоком):
коррекция TX I/Q и меню калибровки, измерение мощности/КСВ,
сброс к заводским настройкам.

## Скачать

Готовые образы собирает GitHub Actions: версии с тегами — на странице
[Releases](https://github.com/He-no3opbc9l/g106-open/releases), каждый коммит — в
[Actions](https://github.com/He-no3opbc9l/g106-open/actions) (artifacts). В zip
релиза лежат образы; файл
`g106_open-<версия>.xgf` шьётся как официальное обновление (см. [Прошивка](#прошивка)), `.bin` —
для SWD. Проще всего — [веб-прошивальщиком](https://he-no3opbc9l.github.io/xg-flasher/): он сам показывает список релизов.

## Сборка

Нужно: `arm-none-eabi-gcc` (проверено на 14.2), GNU make, Python 3, `curl`, `unzip`
(+ `pyserial` для прошивки), по желанию OpenOCD и ST-Link для SWD.

```
make
```

Для сборки нужна официальная прошивка **G106 V1.4b01** (`stock/G106Fw-V1.4b01.xgf`): при первом
запуске `make` скачивает официальный архив обновления и проверяет sha256 файла (без интернета —
положите файл в `stock/` вручную). В репозитории её нет; сборка расшифровывает её и достаёт
оригинальные шрифты и иконки (`tools/extract_stock_gfx.py`), так что стоковой графики в исходниках
нет.

Результат: `build/g106_open.elf`, `.bin` (сырой образ для `0x08020000`) и `.xgf` (зашифрованный
образ для загрузчика). `make stock` дополнительно делает `stock/G106Fw-V1.4b01.bin` (расшифрованное
стоковое приложение) и `stock/G106Fw-V1.4b01.txall.bin` (сток без ограничения передачи по
диапазонам).

Файлы `.xgf` — это просто AES-256-ECB; `tools/xgf.py enc|dec` использует ключ из
`tools/aes_key.hex`.

## Прошивка

### Веб-прошивальщик (браузер, нужен только USB-UART)

**https://he-no3opbc9l.github.io/xg-flasher/** — Chrome / Edge / Opera на компьютере (Web Serial). Выберите релиз (или свой `.xgf`,
`.zip` с ним — например официальный архив Xiegu для возврата на сток — или сырой `.bin`), порт
адаптера, нажмите *Прошить* и включите трансивер, удерживая ручку **громкости**. Файл
расшифровывается и проверяется до отправки; сам загрузчик не трогается. Исходники:
[xg-flasher](https://github.com/He-no3opbc9l/xg-flasher).

### Через стоковый загрузчик (IAP, нужен только USB-UART)

USART1 трансивера (PA9 TX / PA10 RX, 3,3 В, 115200 8N1) подключается к USB-UART адаптеру.

```
make flash-iap PORT=/dev/ttyUSB0
```

Затем включите трансивер, удерживая ручку **громкости**: появится меню загрузчика
(`XG Bootloader(v2.0)`), скрипт выберет обновление и передаст образ по XMODEM-1K. После
`Complete!` выключите и включите трансивер обычным образом. Если меню уже на экране, прошивка
начнётся сразу.

Учтите: после IAP-обновления загрузчик XG включает защиту чтения flash (RDP level 1). Для обычной
работы это не важно, но SWD (ниже) после этого не работает, пока RDP не снят.

### Через SWD (ST-Link, для разработки)

Нужен RDP level 0 (`mdw 0x40023C14` в OpenOCD: байт 1 = `0xAA`). Снятие RDP1 — это полное стирание
всего flash, **включая загрузчик**: делайте это, только если есть полный дамп flash для
восстановления.

```
make flash-swd
```

Скрипт останавливает CPU (**никогда не делает reset**: любой сброс MCU отпускает защёлку питания, и
трансивер выключается), пишет и проверяет приложение, затем выключает трансивер через защёлку
питания. Включите его кнопкой питания. Первая попытка записи иногда завершается таймаутом — скрипт
повторяет её в новой сессии OpenOCD.

### Возврат на сток

- IAP: `python3 -I tools/flash_iap.py /dev/ttyUSB0 stock/G106Fw-V1.4b01.xgf`
- SWD: `make restore-stock-swd` (пишет сток без ограничения передачи).

EEPROM общий и остаётся в стоковом формате, поэтому сток запустится с вашими настройками.

## CAT

Как в стоке: Icom CI-V на USART1 (тот же порт, что для IAP), **19200 8N1**, без эха, принимается
любой адрес CI-V, ID трансивера (`19 00`) — `0x70`. В программах выбирайте трансивер Icom CI-V
(например, профили IC-7000 / Xiegu с адресом 0x70), 19200 бод, PTT через CAT. Значок «C» в верхней
строке экрана показывает, что приходят CAT-кадры.

Поддерживается: частота и режим (`03`/`05`, `04`/`06`, а также VFO A/B через `25`/`26`), режим
данных L-D/U-D (`1A 06`), VFO A/B, A=B, обмен (`07`), PTT (`1C 00`), S-метр (`15 02`), громкость
(`14 01`), мощность TX LOW/MID/HIGH (`14 0A`), предусилитель (`16 02`), блокировка (`16 50`),
ширина фильтра (`1A 03`), границы диапазона (`02`). Разнос (split) пока не сделан. CAT-PTT
сбрасывается, если 60 с не приходит ни одного кадра. Полный список и отличия от стока — в начале
`src/cat.c`.

## Структура репозитория

| путь | |
|---|---|
| `src/` | исходники прошивки (`radio.c` интерфейс, `audio.c` DSP, `spectrum.c` панорама, `settings.c` EEPROM, драйверы) |
